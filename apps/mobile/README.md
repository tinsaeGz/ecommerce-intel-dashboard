# Suq Insights mobile

Expo/React Native application boundary for the native client described in
`SDLC.md`. Native delivery remains demand-triggered after the PWA launch, but
the package is buildable now and shares API types, locale policy, and design
tokens with the web application.

Use `npm run dev:mobile` from the repository root. Platform builds and signing
profiles will be added only when the SDLC trigger is approved.
